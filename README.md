## Архитектура пайплайна

Система использует иерархический многоступенчатый пайплайн:

```
Входной кадр
    │
    ▼
Разбивка на 4 квадранта + апскейл x2
    │
    ├──► YOLOv26 (cigarette/vape detector)
    │
    └──► YOLOv26 (smoke detector)
              │
              ▼
    Confidence Boosting (IoU-взаимодействие детекторов)
              │
              ▼
    DetectionTracker (Hungarian matching, sliding window)
              │
              ▼
    YOLOv8-Pose → TemporalCNN (HPE-классификатор)
              │
              ▼
    CLIP ViT-L/14 + MLP (VLM-верификатор, раз в 30 кадров)
              │
              ▼
    Финальный вердикт (Precision=0.947, Recall=0.956, F1=0.951)
```

**Ключевые решения:**

- Квадрантное разбиение с апскейлом (2x) улучшает детекцию малых объектов на широкоугольных камерах
- Confidence boosting: если bbox сигареты перекрывается с bbox дыма (IoU > 0.1), уверенность умножается на `1.0 + 0.3 * IoU`
- DetectionTracker накапливает свидетельства по нескольким кадрам и подавляет шумовые детекции (min_hits=3, max_age=15)
- TemporalCNN на HPE-признаках фиксирует ритмику движения рука-ко-рту (недоступна при анализе отдельных кадров)
- VLM-верификация вызывается раз в 30 кадров для баланса качества и производительности

## Запуск

### 1. Установка зависимостей

```bash
cd smoking_detection_service
pip install -r requirements.txt
```

### 2. Подготовка моделей

Положите файлы весов в директорию `models/`:

```
models/
├── cigarette_model.pt
├── smoke_model.pt
├── yolo_pose.pt
└── hpe_classifier.pt
```

Qwen3-VL-2B скачивается автоматически при первом вызове с HuggingFace.

```bash
cd smoking_detection_service
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

## Модели

### Детектор сигарет и вейпов — YOLOv26m (`cigarette_model.pt`)

Обучена на micro-датасете (~70k аннотированных изображений из открытых источников).
Тестирование — исключительно на реальных CCTV-записях (out-of-domain).

Оптимальные пороги (подобраны на val-сплите): `cig_conf=0.1`, `final_conf=0.2`.

### Детектор дыма — YOLOv26s (`smoke_model.pt`)

Обучена на micro-датасете из четырёх публичных источников.

### HPE-классификатор — TemporalCNN (`hpe_classifier.pt`)

Одномерная свёрточная сеть на временных последовательностях скелетных признаков YOLOv8-Pose (COCO-17, 9 ключевых точек верхней части тела).
Обучающая выборка: 555 видео (88 с курением), дисбаланс 1:14 компенсирован SMOTE.

### VLM-верификатор — CLIP ViT-L/14 + MLP

MLP-голова поверх замороженных эмбеддингов CLIP ViT-L/14.
Обучена на 3000 кропах (1500 pos + 1500 neg), извлечённых из детекций YOLO.
В инференсе используется Qwen3-VL-2B-Instruct для верификации через текстовый промпт.

## Результаты экспериментов

### Эксперимент 1. Детектирование сигарет и вейпов

Условия: AdamW, cosine LR, 100 эпох, batch=16, seed=42, 5 запусков для 95% ДИ.
Тестирование — out-of-domain (CCTV-записи, отличные от обучающей выборки).

| Модель | Датасет | Сплит | mAP@0.5 | Precision | Recall | F1 |
|---|---|---|---|---|---|---|
| **YOLOv26l (наша)** | small | **test** | **0.787** | **0.845** | **0.811** | **0.828** |
| YOLOv26m (наша) | small | test | 0.763 | 0.816 | 0.801 | 0.808 |
| YOLOv26l (наша) | micro | test | 0.787 | 0.845 | 0.811 | 0.828 |
| YOLOv26m (наша) | micro | test | 0.676 | 0.810 | 0.714 | 0.759 |
| Enos123 YOLOv11m | small | test | 0.471 | 0.715 | 0.529 | 0.608 |
| AarnoStormborn YOLOv5 | small | test | 0.332 | 0.700 | 0.396 | 0.506 |

Лучший результат показывает YOLOv26l, обученный на small-датасете — mAP@0.5 = 0.787, F1 = 0.828.
Open-source детекторы уступают на 35–40% по mAP из-за доменного сдвига.

### Эксперимент 2. Детектирование дыма

| Модель | Датасет | Сплит | mAP@0.5 | Precision | Recall | F1 |
|---|---|---|---|---|---|---|
| **YOLOv26s (наша)** | micro | **test** | **0.733** | **0.740** | **0.724** | **0.732** |
| YOLOv26m (наша) | micro | test | 0.609 | 0.592 | 0.630 | 0.610 |
| TommyNgx YOLOv10 | micro | test | 0.554 | 0.762 | 0.632 | 0.691 |
| leeyunjai YOLOv11s | micro | test | 0.128 | 0.623 | 0.157 | 0.251 |

Open-source детекторы огня/дыма, не адаптированные к CCTV, достигают mAP 0.11–0.55 — специализированное дообучение необходимо.

### Эксперимент 3. Ablation: Confidence Boosting и DetectionTracker

| Конфигурация | Precision | Recall | F1 |
|---|---|---|---|
| YOLO baseline | 0.790 | 0.822 | 0.806 |
| + Smoke detector + Confidence Boosting | 0.845 | 0.811 | 0.828 |
| + DetectionTracker | **0.871** | **0.836** | **0.853** |

Confidence Boosting повышает Precision на 7 п.п.
DetectionTracker нивелирует снижение Recall и даёт дополнительный прирост F1 до 0.853.

### Эксперимент 4. Human Pose Estimation

Обучающая выборка: 555 видео (88 с курением, дисбаланс 1:14 компенсирован SMOTE).
Тестовая выборка: 137 видео (21 с курением). Оценка: 5-кратная кросс-валидация, seed=42.

| Модель | F1 (класс "курение") | ROC-AUC | PR-AUC |
|---|---|---|---|
| RF | 0.567 | 0.981 | — |
| GBM + SMOTE | 0.611 | 0.986 | — |
| MLP (static) | 0.602 | 0.983 | — |
| ST-GCN | 0.727 | 0.974 | 0.733 |
| **TemporalCNN** | **0.800** | **0.997** | **0.838** |
| Pose-Transformer | 0.000 | 0.967 | — |

TemporalCNN (95% ДИ: F1 = 0.800 ± 0.031) — лучший результат.
Одномерная свёртка по временной последовательности фиксирует ритмику движения рука-ко-рту, недоступную статическим классификаторам.

### Эксперимент 5. VLM-верификация (zero-shot CLIP)

| Конфигурация | Порог | Precision | Recall | F1 |
|---|---|---|---|---|
| CLIP RN50 / basic | 0.35 | 0.827 | 0.661 | 0.735 |
| CLIP RN50 / detailed | 0.35 | 0.828 | 0.722 | 0.771 |
| CLIP ViT-L/14 / basic | 0.35 | 0.838 | 0.543 | 0.659 |
| **CLIP ViT-L/14 / detailed** | **0.35** | **0.810** | **0.805** | **0.808** |

Детальный промпт даёт прирост F1 ~10% по сравнению с базовым.
Zero-shot CLIP ViT-L/14 (F1 = 0.808) практически не уступает YOLO-бейзлайну (F1 = 0.806) — весомый результат для верификатора без обучения.

### Эксперимент 6. Дистилляция CLIP-эмбеддингов (CLIP + MLP)

MLP-голова поверх замороженных эмбеддингов CLIP ViT-L/14.
Обучающая выборка: 3000 кропов (1500 pos + 1500 neg).

| Конфигурация | Precision | Recall | F1 |
|---|---|---|---|
| LogReg baseline (CLIP RN50) | 0.878 | 0.918 | 0.897 |
| **MLP (CLIP RN50)** | **0.910** | **0.926** | **0.918** |
| LogReg baseline (CLIP ViT-L/14) | — | — | 0.933 |
| **MLP (CLIP ViT-L/14)** | **0.947** | **0.956** | **0.951** |

MLP превышает LogReg baseline на 14.3 п.п. Кривая обучения сходится к val F1 = 0.949 уже к эпохе 25.

### Итоговые метрики по компонентам пайплайна

| Этап | Precision | Recall | F1 | Delta F1 |
|---|---|---|---|---|
| YOLO baseline | 0.790 | 0.822 | 0.806 | — |
| + Smoke + Confidence Boosting | 0.845 | 0.811 | 0.828 | +0.022 |
| + DetectionTracker | 0.871 | 0.836 | 0.853 | +0.025 |
| + HPE (TemporalCNN) | 0.889 | 0.856 | 0.872 | +0.019 |
| + CLIP ViT-L/14 zero-shot | 0.810 | 0.805 | 0.808 | −0.064 |
| + **CLIP ViT-L/14 + MLP** | **0.947** | **0.956** | **0.951** | **+0.143** |

Совокупный прирост от бейзлайна до финальной конфигурации: **+14.5 п.п. F1 (+18.0% относительно)**.

Снижение на этапе zero-shot CLIP ожидаемо: верификатор без обучения отклоняет часть корректных детекций. Переход к MLP-дистилляции снимает этот эффект.
