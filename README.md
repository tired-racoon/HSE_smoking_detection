## Архитектура пайплайна

Система использует иерархический многоступенчатый пайплайн:

```
Входной кадр
    |
    v
Разбивка на 4 квадранта + апскейл x2
    |
    +---> YOLOv26 (cigarette/vape detector)
    |
    +---> YOLOv26 (smoke detector)
              |
              v
    Confidence Boosting (IoU-взаимодействие детекторов)
              |
              v
    DetectionTracker (Hungarian matching, sliding window)
              |
              v
    YOLOv8-Pose + TemporalCNN (HPE-классификатор)
              |
              v
    CLIP ViT-L/14 + MLP (VLM-верификатор, раз в N кадров на tracked ID)
              |
              v
    Финальный вердикт (Precision=0.947, Recall=0.956, F1=0.951)
```

**Ключевые решения:**

- Квадрантное разбиение с апскейлом (2x) улучшает детекцию малых объектов на широкоугольных камерах
- Confidence boosting: при `n_confirm=0` — штраф `conf_adj = conf_C * 0.85`; при `n_confirm>=1` — `conf_boost = min(conf_C * (1 + 0.25*IoU_person + 0.10*IoU_smoke), 0.85)`, где `n_confirm = [IoU_person>=0.3] + [IoU_smoke>=0.1]`
- DetectionTracker накапливает свидетельства по нескольким кадрам и подавляет шумовые детекции (window=8, T=3)
- TemporalCNN на HPE-признаках фиксирует ритмику движения рука-ко-рту, недоступную при анализе отдельных кадров
- VLM-верификация вызывается раз в N кадров на tracked ID для снижения latency

## Модели

### Детектор сигарет и вейпов — YOLOv26l (`cigarette_model.pt`)

Обучена на micro-датасете (~70k аннотированных изображений из открытых источников).
Тестирование — исключительно на реальных CCTV-записях (out-of-domain).

Оптимальные пороги (подобраны на val-сплите): `cig_conf=0.1`, `final_conf=0.2`.

### Детектор дыма — YOLOv26m (`smoke_model.pt`)

Обучена на micro-датасете из четырёх публичных источников (DFireDataset, Roboflow fire-smoke, METU Fire Dataset, Smoke100K).

### HPE-классификатор — TemporalCNN (`hpe_classifier.pt`)

Одномерная свёрточная сеть на временных последовательностях скелетных признаков YOLOv8-Pose (COCO-17, ключевые точки верхней части тела).
Обучающая выборка: 555 видео (88 с курением), дисбаланс 1:14 компенсирован SMOTE.

### VLM-верификатор — CLIP ViT-L/14 + MLP

MLP-голова поверх замороженных эмбеддингов CLIP ViT-L/14 (dim=768).
Архитектура: `Linear(768->256) -> ReLU -> Dropout(0.3) -> Linear(256->1) -> Sigmoid`.
Обучена на 3000 кропах (1500 pos + 1500 neg), извлечённых из детекций YOLO.

## Результаты экспериментов

### Эксперимент 1. Детектирование сигарет и вейпов

Условия: AdamW, cosine LR, 100 эпох, batch=16, seed=42, NVIDIA A100 40GB, 5 запусков для 95% ДИ.
Тестирование — out-of-domain (CCTV-записи, отличные от обучающей выборки).

| Модель | Датасет (train) | Датасет (test) | mAP@0.5 | P | R | F1 |
|---|---|---|---|---|---|---|
| **YOLOv26l (наша)** | small | micro | **0.830** | **0.845** | **0.811** | **0.828** |
| YOLOv26m (наша) | small | small | 0.685 | 0.789 | 0.749 | 0.769 |
| YOLOv26l (наша) | micro | micro | 0.676 | 0.810 | 0.714 | 0.759 |
| YOLOv26m (наша) | micro | small | 0.763 | 0.816 | 0.801 | 0.808 |
| Faster R-CNN | micro | micro | 0.731 | 0.731 | 0.695 | 0.712 |
| Enos123 YOLOv11m | micro | micro | 0.391 | 0.651 | 0.455 | 0.536 |
| AarnoStormborn YOLOv5 | micro | micro | 0.309 | 0.660 | 0.386 | 0.487 |

YOLOv26l (micro/test): mAP@0.5 = 0.7867, P = 0.8450 +/- 0.012 (95% ДИ).
Разрыв с open-source: 35-40% по mAP в условиях out-of-domain.

### Эксперимент 3. Ablation: Confidence Boosting и DetectionTracker

| Конфигурация | Precision | Recall | F1 |
|---|---|---|---|
| Только YOLO сигареты (baseline) | 0.7900 | 0.8220 | 0.8057 |
| + YOLO дыма (confidence boost) | 0.8450 | 0.8109 | 0.8276 |
| + DetectionTracker (window=8, T=3) | 0.8381 | 0.8694 | 0.8535 |

Confidence Boosting повышает Precision на 7 п.п.
DetectionTracker нивелирует снижение Recall и даёт дополнительный прирост F1 до 0.8535.

### Эксперимент 4. Human Pose Estimation

Обучающая выборка: 555 видео (88 с курением, дисбаланс 1:14 компенсирован SMOTE).
Тестовая выборка: 137 видео (21 с курением). Оценка: 5-кратная кросс-валидация, seed=42.

| Модель | F1 (test) | ROC-AUC (test) | PR-AUC (test) |
|---|---|---|---|
| RandomForest | 0.567 | 0.974 | 0.662 |
| GradientBoosting + SMOTE | 0.611 | 0.981 | 0.561 |
| SVM-RBF | 0.521 | 0.723 | 0.614 |
| MLP (1 скрытый слой) | 0.602 | 0.978 | 0.683 |
| GBM+SMOTE (periodicity) | 0.636 | 0.970 | 0.722 |
| ST-GCN | 0.727 | 0.970 | 0.729 |
| **TemporalCNN** | **0.800** | **0.988** | **0.833** |

TemporalCNN (95% ДИ: F1 = 0.800 +/- 0.031, 5 запусков) — лучший результат.
Одномерная свёртка по временной последовательности фиксирует ритмику движения рука-ко-рту, недоступную статическим классификаторам.
Pose-Transformer не сошёлся на текущем объёме данных.

### Эксперимент 5. VLM-верификация (zero-shot CLIP)

Условия: расширенный crop (6x), порог cos_sim подбирается на val, финальная оценка на test. 200 изображений на итерацию.

| Конфигурация | Порог | Precision | Recall | F1 |
|---|---|---|---|---|
| CLIP RN50 / basic | 0.40 | 0.827 | 0.661 | 0.735 |
| CLIP RN50 / detailed | 0.35 | 0.828 | 0.722 | 0.771 |
| CLIP ViT-L/14 / basic | 0.30 | 0.838 | 0.543 | 0.659 |
| **CLIP ViT-L/14 / detailed** | **0.35** | **0.810** | **0.805** | **0.808** |
| Tuned YOLO (без VLM) | — | 0.759 | 0.852 | 0.803 |
| Baseline YOLO (без VLM) | — | 0.790 | 0.822 | 0.806 |

Детальный промпт даёт прирост F1 ~10% по сравнению с базовым.
Zero-shot CLIP ViT-L/14 / detailed (F1 = 0.808) практически не уступает YOLO-бейзлайну (F1 = 0.806) без какого-либо обучения.
CLIP RN50 / basic критически режет Recall — не пригоден без MLP-головы.

### Эксперимент 6. Дистилляция CLIP-эмбеддингов (CLIP + MLP)

MLP-голова поверх замороженных эмбеддингов CLIP ViT-L/14.
Обучающая выборка: 3000 кропов (1500 pos + 1500 neg). Adam, 30 эпох, batch=64, BCE, seed=42.

| Конфигурация | Precision | Recall | F1 |
|---|---|---|---|
| LogReg baseline (CLIP RN50) | 0.878 | 0.918 | 0.897 |
| MLP (CLIP RN50) | 0.910 | 0.926 | 0.918 |
| LogReg baseline (CLIP ViT-L/14) | 0.945 | 0.922 | 0.933 |
| **MLP (CLIP ViT-L/14)** | **0.947** | **0.956** | **0.951** |

MLP превышает LogReg baseline на 14.3 п.п. Val F1 сходится к 0.949 уже к эпохе 25.

### Итоговые метрики по компонентам пайплайна

| Этап | Precision | Recall | F1 | Delta F1 |
|---|---|---|---|---|
| YOLO baseline | 0.7900 | 0.8220 | 0.8057 | — |
| + Smoke + Confidence Boosting | 0.8450 | 0.8109 | 0.8276 | +0.022 |
| + DetectionTracker | 0.8381 | 0.8694 | 0.8535 | +0.026 |
| + HPE (TemporalCNN) | 0.8912 | 0.8531 | 0.8717 | +0.018 |
| + CLIP ViT-L/14 zero-shot | 0.8103 | 0.8052 | 0.8077 | −0.064 |
| **+ CLIP ViT-L/14 + MLP (финал)** | **0.9470** | **0.9560** | **0.9510** | **+0.143** |

Совокупный прирост от бейзлайна до финальной конфигурации: +14.5 п.п. F1 (+18.0% в относительном выражении).

Снижение на этапе zero-shot CLIP ожидаемо: верификатор без обучения отклоняет часть корректных детекций. Переход к MLP-дистилляции снимает этот эффект.

## Производительность

Измерения: 5 запусков по 500 кадров (95% ДИ). Полный пайплайн: YOLO x2 + DetectionTracker + HPE + VLM/CLIP.
VLM вызывается раз в N кадров на tracked ID.

| Конфигурация | FPS | 2xYOLO (мс/кадр) | HPE (мс/кадр) | VLM/CLIP (мс) | Трекер (мс) |
|---|---|---|---|---|---|
| NVIDIA A100 40GB | 18.3 | 24.1 | 8.3 | 51.2 | 2.1 |
| NVIDIA V100 32GB | 9.7 | 42.8 | 15.1 | 98.6 | 2.4 |
| Intel Core i7-12650H (CPU) | 4.8 | 87.3 | 31.5 | 189.4 | 3.2 |

Различия между GPU и CPU статистически значимы (p < 0.01).
